# Getting Started

This page assumes karhu is installed and a request already reaches `public/index.php` — if not,
start with [Installation](installation.md). Here we add the pieces a real application needs:
middleware, services, validation and errors.

## The shape of an application

```
myapp/
├── app/
│   ├── Controllers/     one class per resource, routes declared as attributes
│   ├── Commands/        CLI commands, #[Command] attributes
│   └── Services/        your own code — karhu has no opinion here
├── config/
│   ├── controllers.php  the list scanned for #[Route]
│   ├── commands.php     the list scanned for #[Command]
│   └── *.php            anything else, read via Karhu\Config\Config
├── public/index.php     front controller — the only web-accessible file
├── bin/console          CLI entry point (optional)
└── cache/routes.php     generated by `route:cache`, gitignored
```

The two registries are explicit lists, not filesystem scans. That is deliberate: the same array
is what gets compiled into the production route cache, so what you see is what ships.

## The request lifecycle

```
Request::fromGlobals()
      ↓
middleware pipeline           ← Cors, Session, Csrf, RequireRole, yours
      ↓
Router::match()
      ↓
  ┌───┴────────────────────┐
  ↓                        ↓
match                  no match / 405
  ↓                        ↓
container->get(Controller)  ErrorHandler → Response
  ↓
$controller->method($request)
  ↓
Response->emit()
```

Two things follow from this that surprise people:

- **Middleware wraps routing**, not just the controller. Middleware runs before a route is even
  matched, so it also sees requests that will 404.
- **Controllers are resolved from the container**, so constructor injection just works.

## 1. Routes

Routes are attributes on public controller methods. The path is the **first** argument.

```php
use Karhu\Attributes\Route;
use Karhu\Http\Request;
use Karhu\Http\Response;

final class IssueController
{
    #[Route('/issues', methods: ['GET'], name: 'issues.index')]
    public function index(Request $request): Response
    {
        return (new Response())->json(['issues' => []]);
    }

    #[Route('/issues/{id}', methods: ['GET'], name: 'issues.show')]
    public function show(Request $request): Response
    {
        $id = $request->routeParams()['id'];

        return (new Response())->json(['id' => $id]);
    }
}
```

Register the class in `config/controllers.php` and it is live. Full detail: [Routing](routing.md).

!!! note "Handlers take the `Request`, not the route parameters"
    `show(Request $request)` — never `show(string $id)`. Read placeholders from
    `$request->routeParams()`.

A handler may also return a `string` (becomes a 200 with that body) or an `array` (becomes JSON).

## 2. Middleware

Middleware is any callable taking `(Request, callable $next)` and returning a `Response`.

```php
$app->pipe(function (Request $request, callable $next): Response {
    $start = microtime(true);

    $response = $next($request);            // run the rest of the stack

    return $response->withHeader(
        'X-Duration-Ms',
        (string) round((microtime(true) - $start) * 1000),
    );
});
```

Not calling `$next()` short-circuits everything after it — that is how the shipped auth and CSRF
middleware reject a request. Order is **FIFO**: first piped, first run.

```php
$app->pipe(new Cors(['origins' => ['https://app.example.com']]))
    ->pipe(new Session())
    ->pipe(new Csrf());
```

Full detail: [Middleware](middleware.md).

## 3. Services and the container

Type-hint a dependency and the container builds it:

```php
final class IssueController
{
    public function __construct(
        private readonly IssueRepository $issues,
        private readonly LoggerInterface $logger,
    ) {}
}
```

Concrete classes auto-wire with no registration. Interfaces need a binding:

```php
$c = $app->container();
$c->bind(LoggerInterface::class, StderrLogger::class);
$c->factory(PDO::class, fn($c) => new PDO(getenv('DATABASE_DSN')));
$c->set(Config::class, $config);
```

Everything the container builds is cached, so each entry is effectively a singleton. Full detail:
[Container](container.md).

## 4. Validation

Describe the input as a DTO, then validate against it:

```php
use Karhu\Attributes\{In, Required, StringLength};
use Karhu\Http\Validation;

final class CreateIssueDto
{
    #[Required]
    #[StringLength(min: 3, max: 120)]
    public string $title = '';

    #[In(['low', 'normal', 'high'])]
    public string $priority = 'normal';
}

#[Route('/issues', methods: ['POST'])]
public function create(Request $request): Response
{
    $data = $request->body();                       // JSON decodes to an array
    $errors = Validation::validate($data, CreateIssueDto::class);

    if ($errors !== []) {
        return (new Response())->json(['errors' => $errors], 422);
    }

    // ... persist
    return (new Response())->json(['ok' => true], 201);
}
```

An empty array means valid. Full detail: [Validation](validation.md).

## 5. Errors

Two seams, and they do different jobs:

```php
// public/index.php
$exceptions = new Karhu\Error\ExceptionHandler();
$exceptions->register();     // safety net: any uncaught throwable → a response

$app = new Karhu\App();
$app->container()->set(Karhu\Http\ErrorHandler::class, new BrandedErrorHandler($twig));
```

In a controller, "this does not exist" is a throw:

```php
throw new Karhu\Http\NotFoundException('issue not found');
```

which routes through the same handler as an unmatched URL, so 404 branding lives in one place.
Full detail: [Error Handling](errors.md).

## Putting it together

```php
<?php
// public/index.php
declare(strict_types=1);

require __DIR__ . '/../vendor/autoload.php';

use Karhu\App;
use Karhu\Config\Config;
use Karhu\Log\{LoggerInterface, StderrLogger};
use Karhu\Middleware\{Csrf, Session};

(new Karhu\Error\ExceptionHandler())->register();

$config = new Config();
$config->loadDir(__DIR__ . '/../config');

$app = new App();
$app->container()->set(Config::class, $config);
$app->container()->bind(LoggerInterface::class, StderrLogger::class);

$app->router()->scanControllers(require __DIR__ . '/../config/controllers.php');

$app->pipe(new Session())->pipe(new Csrf());

$app->run();
```

## Testing what you just built

`handle()` returns the `Response` instead of emitting it, so a test needs no HTTP server:

```php
public function testHelloRoute(): void
{
    $app = new App();
    $app->router()->scanControllers([HomeController::class]);

    $response = $app->handle(new Request([
        'REQUEST_METHOD' => 'GET',
        'REQUEST_URI' => '/hello/world',
    ]));

    self::assertSame(200, $response->status());
    self::assertSame('{"hello":"world"}', $response->body());
}
```

More: [Testing](testing.md).

## Before you deploy

```bash
vendor/bin/karhu route:cache
```

This compiles the route table so production skips reflection entirely. Re-run it on every
deploy — a stale cache silently serves the old routes. See [Deployment](deployment.md).
